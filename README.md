# 🍱 むすめのおべんとう記録

娘のお弁当を記録する、かわいいブログサイトです。
**プログラミングの知識がなくても、GitHub のサイト上だけで更新できます。**

---

## 📂 ファイルのしくみ

| ファイル / フォルダ | なにをするもの？ | さわっていい？ |
|---|---|---|
| `images` フォルダ | お弁当の写真を入れる場所 | ⭕ 写真をここに追加します |
| `obento.js` | 日付・写真・コメントの記録リスト | ⭕ ここに記録を追加します |
| `index.html` | ページの骨組み | ❌ さわらなくてOK |
| `style.css` | デザイン（色や形） | ❌ さわらなくてOK |
| `health.html` / `health.css` / `health.js` ほか | 🍎 単独アプリ「カロリーノート」（下で説明） | ❌ さわらなくてOK |
| `foods.js` | カロリーノートの食品データベース | ⭕ 食品を増やしたいときだけ |

ふだん編集するのは **`images` フォルダと `obento.js` の2つだけ** です。

## 🌍 サイトを公開する方法（最初に1回だけ）

1. GitHub でこのリポジトリ（`bento-blog`）のページを開く
2. 上のほうにある **「Settings」**（設定）をクリック
3. 左のメニューから **「Pages」** をクリック
4. 「Branch」のところで **`main`** を選び、フォルダは **`/ (root)`** のまま **「Save」** を押す
5. 1〜2分待ってからページを再読み込みすると、上のほうに
   `https://あなたのユーザー名.github.io/bento-blog/`
   というアドレスが表示されます。これがブログのアドレスです！🎉

> アドレスは家族や友だちに教えれば、誰でもスマホやパソコンから見られます。

## 📸 ふだんの更新のしかた（2ステップ）

### ステップ1：写真をアップロードする

1. GitHub でこのリポジトリを開き、**`images` フォルダ**をクリック
2. 右上の **「Add file」→「Upload files」** をクリック
3. お弁当の写真をドラッグ＆ドロップ（またはファイルを選択）
4. 下にある緑色の **「Commit changes」** ボタンを押して保存

> 💡 **写真の名前のコツ**：日付をファイル名にすると分かりやすいです。
> 例：`2026-06-12.jpg`
> ※ ファイル名は **半角の英数字**（日本語の名前は避ける）にしてください。

### ステップ2：記録を1件追加する

1. リポジトリのトップに戻り、**`obento.js`** をクリック
2. 右上の **えんぴつマーク ✏️（Edit）** をクリック
3. `const obentoList = [` と書いてある行の **すぐ下** に、次の5行をコピーして貼り付ける：

   ```
  {
    date: "2026-06-12",
    photo: "images/2026-06-12.jpg",
    comment: "きょうはからあげ弁当！おかわりしたいって言ってくれた♪",
  },
   ```

4. 日付（date）・写真のファイル名（photo）・コメント（comment）を書きかえる
   - `date` は「年-月-日」の順、半角の数字とハイフンで
   - `photo` の名前は、ステップ1でアップロードした写真の名前とぴったり同じに
5. 右上の緑色の **「Commit changes...」→「Commit changes」** を押して保存

これだけで完了です！1〜2分後にブログのページを再読み込みすると、新しいお弁当が一番上に表示されます。

> 💡 順番を気にする必要はありません。日付の新しいものが自動で上に並びます。

## 📝 お弁当がなかった日のメモ

休校や行事などでお弁当がなかった日は、`obento.js` の**いちばん下**にある `oyasumiList` に1行追加すると、カレンダーのその日に文字で表示されます。

```
  { date: "2026-06-03", note: "台風のため休校" },
```

※ 国の祝日（GW・海の日など）は自動で表示されるので、書かなくて大丈夫です。

## ✏️ そのほかのカスタマイズ

### サイトの名前を変えたいとき

`index.html` を開いて（えんぴつマークで編集）、
`むすめのおべんとう記録` と書いてある部分（2か所あります）を好きな名前に書きかえて保存してください。

### サンプルの記録を消したいとき

`obento.js` の中の、`sample1.svg` と `sample2.svg` を使っている
`{` から `},` までのかたまりをそれぞれ削除して保存してください。

## 🍎 カロリーノート（単独アプリ）の使い方

食事のカロリー・塩分・野菜量・果物量を記録できる **「カロリーノート」** が入っています。
ブログとは独立したアプリで、ブログのページからは見えません。

**アプリのアドレス：** `https://あなたのユーザー名.github.io/bento-blog/health.html`

### 📱 スマホでアプリのように使う（おすすめ）

上のアドレスをスマホで開いて「ホーム画面に追加」すると、
専用アイコンから普通のアプリのように起動できます（電波がない場所でも開けます）。

- **iPhone（Safari）**：共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）

### できること

| タブ | できること |
|---|---|
| きょう | その日のカロリー・塩分・野菜・果物・PFCを目標と比べて表示 |
| 食事きろく | 📷 写真をAIで解析して食材とグラム数を自動入力（確認して修正OK）／食品検索で手動追加 |
| からだ | 体重・睡眠時間・歩数・水分の記録とグラフ |
| もくひょう | 目標体重と目標日から、1日の適正カロリーなどを自動計算 |
| せってい | AIのAPIキー設定、データのバックアップ（書き出し・読み込み） |

### はじめかた（2ステップ）

1. **「もくひょう」タブ**で、性別・年齢・身長・体重・目標体重を入れて保存する
   → あなたに合った1日の目標カロリーなどが自動で計算されます
2. **「食事きろく」タブ**で食べたものを記録する
   - 食品名で検索して追加（無料・設定不要）
   - または写真をAIで解析して自動入力（下の設定が必要）

### 📷 写真のAI解析を使いたいとき

**🆓 無料のコピペ方式（おすすめ・準備不要）**

1. 「食事きろく」タブの **「① お願い文をコピーする」** を押す
2. 無料のAIチャットアプリ（[claude.ai](https://claude.ai/)・Gemini・ChatGPTなど）を開き、
   **食事の写真を添付**して、お願い文を貼り付けて送る
3. AIの返事をぜんぶコピーして、カロリーノートの貼り付け欄に貼り、「取り込む」を押す

→ 食材とおおよそのグラム数が一覧に入ります。APIキーもお金も不要です。

**⚡ ボタン1つの自動解析（APIキーが必要・有料）**

毎回のコピペを省きたいときは、[platform.claude.com](https://platform.claude.com/) でAPIキーを取得して
「せってい」タブに保存すると、写真を選ぶだけで解析できます（1回あたり数円〜十数円）。
キーはこの端末のブラウザの中だけに保存されます。

どちらの方法でも、AIの推定は「おおよその予想」です。隠れている食材や量は、表で確認して直してください。

### 🔒 記録データについて

- 記録は**見ている端末のブラウザの中**に保存されます（GitHubにはアップロードされません）
- 別の端末に移したいときは「せってい」→「データを書き出す／読み込む」を使ってください

## ❓ こまったときは

| こんなとき | 確認すること |
|---|---|
| 写真のかわりに「写真が見つかりませんでした」と出る | `obento.js` の `photo` のファイル名と、`images` フォルダの中の写真の名前が**1文字でも違っていないか**（大文字・小文字も区別されます） |
| ページに何も表示されなくなった | `obento.js` で `"`（ダブルクォーテーション）や `,`（カンマ）を消してしまっていないか |
| 更新したのにページが変わらない | 1〜2分待ってから、ページを再読み込み（スマホなら下に引っぱって更新） |
